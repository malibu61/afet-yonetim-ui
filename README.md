# README — Afet Yönetim web arayüzü (`afet-yonetim-ui`)

Bu proje, “AFETWATCH” adlı harita odaklı ön yüzdür; React 19 ve Next.js 16 (App Router, `src/app`) ile yazılmıştır. Ana sayfa sunucu/istemci bileşenleriyle .NET API’den deprem listesini `GET api/Deprem` üzerinden periyodik veya yenileme ile çeker; hata durumunda kullanıcıya mesaj gösterir ve tekrar deneme sunar. Harita motoru Mapbox GL olduğu için ağır paket istemci tarafında `dynamic` import ile yüklenir (`ssr: false`). `MapViewTabs` bileşeni iki sekme sunar: biri son 24 saat depremlerini haritada nokta olarak gösterir, diğeri Türkiye il düzeyinde afet risk haritasını API’den gelen koordinat ve risk verisiyle çizer; risk ve gerekirse yapay zekâ destekli özet uçları `RiskHaritasi` ve ilgili API çağrıları üzerinden bağlanır. Tüm API kök URL’si `src/constants/api.js` içinde `NEXT_PUBLIC_API_BASE_URL` ile verilir; tanımlanmazsa varsayılan `https://localhost:7232` kullanılır — bu, .NET’in HTTPS geliştirme portu ile uyumludur.

Kurulum: `npm install`, geliştirme sunucusu `npm run dev` (veya `yarn dev`, `pnpm dev`, `bun dev`). Varsayılan geliştirme adresi [http://localhost:3000](http://localhost:3000)’dir. Üretim için `npm run build` ve ardından `npm run start`; kod kalitesi için `npm run lint`. Harita için `.env.local` dosyasında `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` zorunludur; token tarayıcıya gider, kısıtlı public token kullanın. Backend ayrı süreçte çalışmalıdır (.NET tipik olarak 7232/5108); sadece UI’yi açmak deprem veya risk verisini doldurmaz; Kafka, tüketiciler ve gerekirse Python script’leri de çalışır durumda olmalıdır.

Özet: Bu depo parçası kullanıcıya deprem ve risk verisini harita üzerinde sunar; veri kaynağı olarak .NET API’ye güvenir, Mapbox ve ortam değişkenleri ile yapılandırılır.
